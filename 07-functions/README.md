# Functions

Function is a block of commands that performs a specific task. Functions are used to avoid repetition of code.

## Why do we use functions?

- Reuse code (write once, use many times)
- Keep scripts clean & readable
- Organize logic into meaningful blocks
- Easier debugging & maintenance

```bash
function_name() {
    # commands
}
```

```bash
#!/bin/bash

# Function definition
greet() {
  echo "Hello, world!"
}

# Call the function
greet
```
